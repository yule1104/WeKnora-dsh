# 云妆内部问答使用智能推理模板

按用户指定方案执行：内部智能体从 builtin-smart-reasoning 派生，绑定现有私域 Qwen，支持多步检索、分页列文档、读原文；仅开放内部只读工具和会话附件读取。关闭联网、MCP、跨会话记忆、技能及沙箱；未配置获准的 Rerank 时使用原始检索顺序，不回退云端。每轮输出预算至少 8192 tokens。已有空间配置幂等同步，锁定会话不解锁。

后端仅在持久锁定由 false 变为 true 的请求里标记 switched；前端同步状态但仅在该转换首次展示提示，连续追问、SSE 重放与刷新不重复提示。两个智能体均使用 Agent 模式。

验证：先写失败测试；验证模板迁移、私域工具边界、Rerank 隔离和通知状态；运行相关后端/前端测试与构建；保留现有界面改动发布至 18082；使用合成百份档案验证分页工具、连续追问、旧会话和附件。核验后提交、合并并推送 yunzhuang-ai，保留镜像、配置及数据库回滚备份。
