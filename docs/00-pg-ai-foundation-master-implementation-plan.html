现网数据库基线与一期存储约束

2026-09-30 已通过服务器运行容器、应用连接配置、网络及挂载信息只读核对。WeKnora 与星火同机部署，PG、Redis 均为不同实例；星火业务主库为 MySQL。

用途现网实例 / 容器数据库
WeKnora PostgreSQLWeKnora-postgresWeKnora
星火知识库 PostgreSQLmem0-postgres-1knowledge_base
星火业务 MySQLpangu-mysql（宿主机 3308）system_base

星火 Redisredis（Redis 6.2，宿主机 6379）DB 编号本次未核对；实例与 WeKnora 独立
一期固定决策：Gateway 复用 WeKnora-postgres，新建独立数据库 dsh_runtime 和专用最小权限账号，不复用 postgres 超级用户凭据，不以 WeKnora 库内独立 schema 代替独立库。Redis 复用 WeKnora-redis，使用部署前核验未占用的独立 DB 和 dsh: key 前缀。

Redis 不使用 WeKnora 的 DB 0；若启用 Langfuse，还须避开其实际 DB（默认 1）。DB 2 仅为候选，核验未占用后才能配置。一期不新增 PG、Redis 实例，不合并或迁移星火现有数据库。

PostgreSQL 保存 run、幂等记录、事件游标、终态和产物索引，支持查询与重启恢复；Redis 仅用于锁、短期状态和队列，不能作为唯一事实源；大产物存放于对象存储或受控文件目录。

Gateway 独立管理迁移、迁移记录和按库备份/恢复，只读写 dsh_runtime；不得直连或读写 WeKnora、星火业务表。知识与业务调用经授权的 WeKnora API / 星火 API、MCP 完成。

共享实例边界：CPU、内存和故障影响范围仍共享；Redis DB 与前缀仅为逻辑隔离。实例升级需协调，Gateway 连接数与任务并发需受控，后续可将独立库迁出。不得对共享 Redis 执行 FLUSHALL。

存储验收：记录实际实例、库名、账号名、Redis DB 与前缀（不含密码）；验证账号权限与迁移边界、Redis 隔离、Gateway 重启后的 run 持久化，以及独立库备份恢复不改写其他业务数据。

升级兼容边界

Gateway 降低 Go 合并成本，但产品仍包含前端和部署定制。

部分一期变化上游升级影响
WeKnora Go Agent 主链路不因 DSH/星火迁移修改冲突概率显著降低
WeKnora Vue新增项目工作台、导航和业务页面仍需合并并回归前端
Gateway独立版本和数据库与 WeKnora 独立升级，只需契约兼容
星火 FastAPIIntegration BFF、绑定、草稿 MCP按领域服务版本独立升级
Runtime Adapter一期不存在未来启用后才增加 Go 合并点
生产升级仍需演练：固定官方版本 → 合并到定制 fork → 构建镜像 → 数据库备份 → 测试升级 → API/MCP/SSE/页面回归 → 灰度 → 保留回滚点。
05

一期完成标准

每一项都需要可重复的验证证据。

平台

项目工作台只需一次登录；租户、项目和撤权校验有效；页面数据继续来自星火事实源。

Agent

简单 RAG 不调用 DSH；复杂任务经 Gateway MCP；候选不能自动确认或发布。

工程

run 幂等、可取消、可恢复、可审计；上游升级和业务改造能分别回归与回滚。
